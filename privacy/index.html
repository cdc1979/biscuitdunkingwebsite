THE SHORT VERSION

Privacy, plain
and simple.

This website does not ask who you are or collect personal details. It reads global biscuit-dunking totals from the existing game summary service.

LAST UPDATED: 23 SEPTEMBER 2026

What this website uses

The homepage requests aggregate gameplay statistics: total biscuits dunked, the most popular biscuit and its run count, completed runs, average dunk life, average dunks per run, and biscuits dropped in. This informational website only reads those summary values; it does not submit gameplay or score data.

Personal information

This website does not request or store your name, email address, phone number, account details, or other personal information. It uses biscuit-dunking statistics to show how the game is being played.

Cookies and tracking

This website does not set advertising cookies or use analytics trackers or account sign-in.

Summary service

Global figures are read from the existing Biscuit Dunking summary API. That service is hosted separately from this website. Its hosting provider may process technical connection information to deliver the request.

Questions

If you have a question about the game’s stored score data, please get in touch with the site owner through the channel where you found this game.
